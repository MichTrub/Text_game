# Text_game
Text-Based RPG Adventure
A console RPG made in Python where players fight monsters, collect equipment, buy items from shops, level up, and defeat a boss.

Features
Two playable classes: Warrior and Assassin
Turn-based combat system
Inventory and equipment management
Shops for buying and selling items
Experience and leveling system
Status effects such as poison
Randomly generated map encounters
Boss battle
Technologies Used
Python 3
Random module
